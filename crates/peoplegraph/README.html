PeopleGraph CLI

Graph queries and explicit merge-review writes over the Obsidian Gmail CRM contact-index.json cache.

Build

cargo build --release

Usage

Pass an explicit cache path, set PEOPLEGRAPH_CACHE, or run from a vault that contains .obsidian/plugins/gmail-crm/contact-index.json.

peoplegraph describe
peoplegraph --cache /path/to/contact-index.json find-person "Maya Rivera"
peoplegraph --cache /path/to/contact-index.json score maya.rivera@disney.com
peoplegraph --cache /path/to/contact-index.json who-knows --company Disney
peoplegraph --cache /path/to/contact-index.json get-neighbors maya.rivera@disney.com
peoplegraph --cache /path/to/contact-index.json get-edges --from maya.rivera@disney.com --to sam.lee@example.org
peoplegraph --cache /path/to/contact-index.json suggest-duplicates --limit 25 --min-confidence 0.82
peoplegraph --cache /path/to/contact-index.json merge-queue --status pending --limit 25
peoplegraph --cache /path/to/contact-index.json apply-merge maya.rivera@disney.com maya@disney.com
peoplegraph --cache /path/to/contact-index.json dismiss-merge maya.rivera@disney.com maya@disney.com --reason not_duplicate
peoplegraph --cache /path/to/contact-index.json propose-merge maya.rivera@disney.com maya@disney.com

All commands emit a stable JSON object on stdout. Query commands are read-only; propose-merge, dismiss-merge, and apply-merge intentionally update local merge metadata.

Packaging

From the repository root:

npm run build:peoplegraph
npm run package:peoplegraph

The package step copies the optimized binary to bin/peoplegraph.
