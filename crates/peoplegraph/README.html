PeopleGraph CLI

Graph queries, read-only remote access, and explicit merge-review writes over the Obsidian Gmail CRM contact-index.json cache.

Build

cargo build --release

Usage

Install from Homebrew:

brew tap kayacancode/tap
brew install peoplegraph

Pass an explicit cache path, set PEOPLEGRAPH_CACHE, or run from a vault that contains .obsidian/plugins/gmail-crm/contact-index.json.

peoplegraph describe
peoplegraph --cache /path/to/contact-index.json find-person "Maya Rivera"
peoplegraph --cache /path/to/contact-index.json score maya.rivera@disney.com
peoplegraph --cache /path/to/contact-index.json who-knows --company Disney
peoplegraph --cache /path/to/contact-index.json get-neighbors maya.rivera@disney.com
peoplegraph --cache /path/to/contact-index.json get-edges --from maya.rivera@disney.com --to sam.lee@example.org
peoplegraph --cache /path/to/contact-index.json contact-card maya.rivera@disney.com
peoplegraph --cache /path/to/contact-index.json suggest-duplicates --limit 25 --min-confidence 0.82
peoplegraph --cache /path/to/contact-index.json import-cache --source kaya /path/to/kaya/contact-index.json
peoplegraph --cache /path/to/contact-index.json suggest-external-merges --source kaya --limit 25
peoplegraph --cache /path/to/contact-index.json apply-external-merge --source kaya --primary maya.rivera@disney.com --external maya@disney.com
peoplegraph --cache /path/to/contact-index.json dismiss-external-merge --source kaya --primary maya.rivera@disney.com --external maya@disney.com --reason not_same_person
peoplegraph --cache /path/to/contact-index.json merge-queue --status pending --limit 25
peoplegraph --cache /path/to/contact-index.json apply-merge maya.rivera@disney.com maya@disney.com
peoplegraph --cache /path/to/contact-index.json dismiss-merge maya.rivera@disney.com maya@disney.com --reason not_duplicate
peoplegraph --cache /path/to/contact-index.json propose-merge maya.rivera@disney.com maya@disney.com

All commands emit a stable JSON object on stdout. Query commands are read-only; merge and import commands intentionally update local sidecar or cache metadata.

Remote Query Mode

Run this on the machine that has Botwick's source-of-truth contact-index.json:

export PEOPLEGRAPH_TOKEN="use-a-long-random-token"
peoplegraph --cache /path/to/contact-index.json serve --bind 127.0.0.1:8787

Then query from a client with the same token:

peoplegraph --host http://127.0.0.1:8787 --token "$PEOPLEGRAPH_TOKEN" who-knows --company Disney
peoplegraph --host http://127.0.0.1:8787 --token "$PEOPLEGRAPH_TOKEN" find-person "Harper Reed"
peoplegraph --host http://127.0.0.1:8787 --token "$PEOPLEGRAPH_TOKEN" contact-card harper@2389.ai

Remote mode supports read-only commands. Merge commands stay local-only in V1 and should be applied on the source-of-truth machine after review.

External Source Staging

Import another Gmail CRM plugin user's local cache into external-sources.json without overwriting the source-of-truth graph.

peoplegraph --cache /botwick/contact-index.json import-cache --source kaya /kaya/contact-index.json
peoplegraph --cache /botwick/contact-index.json suggest-external-merges --source kaya
peoplegraph --cache /botwick/contact-index.json contact-card harper@2389.ai

apply-external-merge only merges objective identity fields such as aliases/emails and missing company/role fields. Source-specific relationship context remains separate.

Packaging

From the repository root:

npm run build:peoplegraph
npm run package:peoplegraph

The package step copies the optimized binary to bin/peoplegraph.
