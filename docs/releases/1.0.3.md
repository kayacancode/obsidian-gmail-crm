# People Atlas 1.0.3

Settings are now searchable in Obsidian, refresh through the supported settings API, and retain their existing values. UI elements use their parent window and Obsidian helpers; browser timers are explicitly window-scoped. Obsolete direct build dependencies have been removed.

Hosted apps now live in the public [services repository](https://github.com/kayacancode/people-atlas-services), with independent type and test checks. The pinned submodule retains cross-runtime graph-contract tests. The hosted deployment and plugin ID are unchanged.
