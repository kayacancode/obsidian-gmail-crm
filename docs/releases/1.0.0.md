# Gmail CRM 1.0.0

Gmail CRM brings Gmail relationship activity into your Obsidian vault, with local people notes, relationship scoring, and optional personal and shared People graphs inside an Obsidian tab.

- Open the People graph inside Obsidian, with browser-based sign-in and shared-network selection.
- Keep relationship mapping current after contact sync without requiring AI.
- Protect Google connection with OAuth state validation and PKCE, including overlapping-connect protection.
- Respect Obsidian’s trash preference when cleaning up an older generated quadrant view.
- Clarify Google permission scopes, optional Anthropic note processing, hosted People accounts, and local credential storage.

Requires Obsidian desktop 1.15.0 or later. Gmail sync requires Google authorization; optional hosted graph features require internet and a People account. Read the README and PRIVACY.md before connecting accounts.

Install the attached main.js, manifest.json, and styles.css together in your vault’s .obsidian/plugins/gmail-crm folder. SHA256SUMS verifies the release assets. Community-directory availability depends on Obsidian’s review and approval.
