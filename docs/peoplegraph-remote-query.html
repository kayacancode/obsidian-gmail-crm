Remote Query-Only

Query Botwick's PeopleGraph from another computer.

Remote users only need the PeopleGraph CLI, the Botwick host URL, and a bearer token. They do not need Obsidian, the Gmail CRM plugin, Gmail credentials, or the source vault.

Current connection target

PeopleGraph 0.3.1 Read-only remote mode Token required 
http://100.92.219.31:8787

Keep the token private. The examples below use 93cf5a...9644 as a redacted placeholder.

Connect

Use a prefix for one-off commands, or export the host and token once per terminal session. Add --remote to every query so the CLI errors instead of falling back to a local Obsidian cache.

Install the CLI once

Install PeopleGraph from the Homebrew tap.

brew tap kayacancode/tap
brew install peoplegraph
peoplegraph version
Expected version: 0.3.1 or newer.

Use the prefix one-off

Paste this before any command if you do not want environment variables.

peoplegraph --remote --host "http://100.92.219.31:8787" --token "93cf5a...9644"
Replace the redacted token with the real token.

Set it once recommended

After exporting these, commands can be shorter.

export PEOPLEGRAPH_HOST="http://100.92.219.31:8787"
export PEOPLEGRAPH_TOKEN="93cf5a...9644"
These exports last for the current terminal session.

Smoke test check

Confirm the server and token work before running lookups.

peoplegraph --remote version
peoplegraph --remote describe
If this fails, check the token, host, and network.

Lookup Commands

These commands query Botwick's source-of-truth cache remotely and do not write to the graph.

Find a person lookup

Fuzzy match by name, email, or alias. Returns the top 10 by default.

peoplegraph --remote find-person "Harper Reed"
peoplegraph --remote find-person "Harper Reed" --limit 20
Use when you do not know the exact email.

Score one email score

Relationship score for one email: combined score, depth, recency, and quadrant.

peoplegraph --remote score harper@2389.ai
Quadrants include nurture, developing, and re-engage.

Contact card card

Minimal source-aware card for one person: name, emails, company, aliases.

peoplegraph --remote contact-card "Harper Reed"
Useful before deciding whether a merge suggestion is plausible.

Who knows a company company

Everyone at a company or domain, ranked by relationship score.

peoplegraph --remote who-knows --company betaworks
peoplegraph --remote who-knows --company betaworks --limit 10
Works with company names and domains.

Neighbors graph

Shows who is connected to a person once edge data exists.

peoplegraph --remote get-neighbors harper@2389.ai
Best after the plugin has written relationship edges.

Specific edge graph

Returns the relationship edge between two specific people.

peoplegraph --remote get-edges --from harper@2389.ai --to john@betaworks.com
Use when you need the direct connection evidence.

Cleanup / Review

Remote users can inspect suggestions and queue state, but source-of-truth write commands still run on Botwick's computer.

Suggest duplicates review

Find likely duplicate contacts in the cache.

peoplegraph --remote suggest-duplicates
peoplegraph --remote suggest-duplicates --limit 10 --min-confidence 0.85
Returns confidence, reasons, and next action commands.

Merge queue queue

See pending merge proposals already staged on the source-of-truth graph.

peoplegraph --remote merge-queue
peoplegraph --remote merge-queue --status pending
Use --status all when you want historical queue entries.
Remote mode is read-only. Approve/reject/apply commands such as apply-external-merge, dismiss-external-merge, import-cache, and apply-merge must run on Botwick's source-of-truth computer.

Troubleshooting

command not found: peoplegraph

Install the CLI or make sure Homebrew's bin directory is on the shell path.

brew tap kayacancode/tap
brew install peoplegraph
unauthorized

The token is missing, expired, or not the same token Botwick's server expects.

export PEOPLEGRAPH_TOKEN="paste-the-real-token"
Connection refused or timeout

The Botwick server may not be running, the Tailscale/private network may be disconnected, or the host URL is wrong.

export PEOPLEGRAPH_HOST="http://100.92.219.31:8787"
peoplegraph --remote version
No results for a company

Try the domain, a person lookup, or a higher limit. The source cache may need a fresh sync on Botwick's computer.

peoplegraph --remote who-knows --company betaworks.com --limit 25
peoplegraph --remote find-person "Betaworks"
